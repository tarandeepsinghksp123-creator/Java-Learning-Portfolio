# Java Learning Portfolio

A collection of Java programs written while learning core Java and Object-Oriented Programming. The repository is organized by topic to make the learning progression easy to follow.

## Topics covered

- Java basics, operators, type conversions, and conditionals
- Loops, methods, and pattern printing
- Arrays and array-based problem solving
- Number programs: prime numbers, Armstrong numbers, HCF, LCM, perfect numbers, and sums
- Classes, objects, constructors, copy constructors, and encapsulation

## Repository structure

- `01-Basics/`
- `02-Loops/`
- `03-Patterns/`
- `04-Arrays/`
- `05-Number-Programs/`
- `06-Methods-and-Problem-Solving/`
- `07-OOP/`

## How to run a program

1. Open a terminal in the folder containing the `.java` file.
2. Compile it: `javac FileName.java`
3. Run it using its class name: `java ClassName`

Each program is a separate practice exercise. Some programs use console input, so follow the prompts in the terminal.
